# Multi Brain Master Index

File ini hanya pointer ke sub-index. BUKAN log kerja utama.

## Rules

- Jaga tetap pendek dan mudah dipindai (< 1 menit).
- Satu baris per bucket.
- Update timestamp saat bucket dapat entry baru.
- Log kerja detail ada di `.multibrain/indexes/*.md`, bukan di sini.

## Buckets

- `nama-bucket` — deskripsi scope singkat — update terakhir: YYYY-MM-DD HH:MM WIB -> .multibrain/indexes/nama-bucket.md
